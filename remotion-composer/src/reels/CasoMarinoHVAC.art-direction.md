# Art-direction — "Caso real: Marino HVAC" (reel 3/4)

## Paleta y tipografia
Mismo playbook ember-only del piloto y del reel 2: `#0A0A0A` / `#141414` /
`#FF6B1A` / `#F5F5F5` / `#9AA0A6`. El i2v hero shot se genero con negativos
explicitos anti cian/violeta/teal y el prompt pide explicitamente "luz
dorada", "paleta calida tungsteno/ember" — verificado en los 3 frames de
sanity-check (0.3s/2.5s/4.7s): identidad, ropa e iluminacion consistentes,
sin warping, manos bien formadas, cero cian/violeta.

## Signature device (nuevo para este reel)
`TagRevealList` — lista boxless de tags con tick vertical ember que crece.
Es el device que responde a la restriccion mas dura de este reel (cero
cifras inventadas): en vez de un dashboard de metricas fabricadas, muestra
los PASOS reales que el post describe (servicio/zona/urgencia/cita), que
son verificables palabra por palabra contra el texto fuente.

## Por que NO hay un dashboard de KPIs con numeros
El catalogo Remotion ya tiene `KPIGrid` (metricas animadas con contador).
Se considero y se DESCARTO deliberadamente para este reel: el post no da
ninguna cifra para Marino HVAC ("conversaciones que antes se perdian ahora
se capturan" es cualitativo, no un porcentaje). Poner un KPIGrid con
numeros habria significado inventar datos que el post no respalda —
violacion directa de la regla anti-claims. `TagRevealList` logra el MISMO
objetivo narrativo (mostrar 'el proceso funcionando') sin fabricar nada.

## Distinctness review
Un solo hero real (no dos, como el piloto) — suficiente para anclar el
caso en la realidad de campo sin volver el reel un montaje de stock. El
resto es 100% motion-autorado, mismo lenguaje de chat que el piloto y el
reel 2 (deliberado: es la misma marca, la misma serie), pero CasoMarinoHVAC
es el UNICO reel de los 4 con footage real — distintivo dentro de la serie.
